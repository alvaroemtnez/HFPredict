# Roadmap

Open work only. Done items go into the commit history and CHANGELOG.md.

## Before the first release

- **Icon**: the current mark (an earth disc with a reach blob of cells, a dashed
  distance ring and the station) is a first proposal, generated by
  `tools/gen-icons.py`. To be discussed with the owner.
- **Release keys**: Android keystore and GPG key, Forgejo secrets
  (docs/releasing.md); then the fingerprints into docs/verifying.md.
- **Translations review**: es, ca are written natively; de, ja and ar start from
  HFcast's translations and need a native reader's pass.
- **Test on real devices**: a phone and a tablet (GrapheneOS), and a GNOME
  laptop through the Flatpak.

## Later

- **Flathub** submission (flatpak-cargo-generator sources instead of the local
  vendor step) and **F-Droid** metadata.
- **Local time zones**: local time is solar (an hour per 15° of longitude), as in
  HFcast; a coordinate-to-zone lookup (tzf) would give legal time with summer
  time, at a few MB.
- **Compute maps ahead** (HFcast's background job): left out on purpose (it
  needs a foreground service and the notification permission). Revisit if map
  computation feels slow on old devices; the cache covers browsing.
- **Device benchmark** (HFcast's "Measure this device"): only needed with the
  above.
- **Tap a map cell** for the chance of contact there (the probe shows the
  quality band; a path forecast to that point would give the number).
- **Coastline smearing** near the antipode rim of the map.
